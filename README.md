# A Bíblia que Você Não Leu

Landing page editorial de vendas para o e-book **A Bíblia que Você Não Leu**, com estética cinematográfica, responsiva e foco em leitura, contexto e reflexão.

## Conteúdo

- Hero editorial com imagem de uma Bíblia aberta.
- Seções de proposta, curiosidade, identificação e descoberta.
- Grade de temas abordados no e-book.
- Seção de autor com biografia e credenciais editáveis.
- Oferta com CTA para checkout.
- FAQ interativo.
- Layout responsivo para desktop e mobile.

## Rodando localmente

```bash
pnpm install
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm run build
```

## Personalização antes da publicação

Substitua os campos entre colchetes na seção do autor e atualize os dados comerciais da oferta:

- Nome e biografia do autor.
- Formação, experiência e credenciais.
- Preço real do e-book.
- Link real do checkout da Hotmart.
- E-mail de suporte.
- Prazo e condições de garantia.
